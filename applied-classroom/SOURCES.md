# Source books

Each course folder has a `sources.md` with copyable titles and a `sources/` folder for PDFs.

| List | Course folder | On disk |
|---|---|---|
| JavaScript | `javascript/` | 4 books + Responsible JS slides/audio |
| TypeScript | `typescript/` | 3 books |
| HTML, CSS, accessibility | `html/` and `css/` | Duckett, Inclusive Components, CSS in Depth 1st |
| Data structures and algorithms | `data-structures/`, `algorithms/`, `leetcode/` | split by use |
| React and frontend | `platform/` | 3 books (this app is the React project) |
| Node.js, backend, API | `api/` | titles only, no PDFs yet |
| SQL and databases | `database/` | 2 books |

When writing `quiz.json`, cite a book in `reference` so the runner can open notes, page, and excerpt:

```json
"reference": {
  "section": "Values",
  "book": "Eloquent JavaScript, 4th Edition by Marijn Haverbeke",
  "page": 14,
  "excerpt": "There are six basic types of values in JavaScript: numbers, strings, Booleans, objects, functions, and undefined values."
}
```

Paste titles below into Google if you need another copy.
