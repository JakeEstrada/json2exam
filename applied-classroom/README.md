# Applied Classroom Development

The learning platform is the continuous project for the entire program.
Every course will later produce lessons, exercises, assessments, or platform features.

Each topic already has `quiz.json` and `notes.md`. Paste questions into
`quiz.json` the same way as the Requirements Engineering and Applied Software
Process banks, then refresh. Start stays off until the file has questions.

Source books live in each course `sources/` folder. Copyable titles:
`SOURCES.md`. Product brief for ChatGPT: `JSON2EXAM.md`. Ordered path:
`STUDY_PLAN.md`. The first six JavaScript language topics are ready to study.
