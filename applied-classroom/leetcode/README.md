# LeetCode-Style Practice

Topic modules. Memorize high-level pattern skeletons, then recognize them on real problem statements.

## Modules (all ready)

- Arrays - hash map, two pointers, sliding window, binary search, prefix aggregates
- Strings and hash - frequency maps, windows, palindromes, stacks
- Linked lists - reverse, fast/slow, dummy merge, LRU
- Trees - DFS, BFS levels, BST bounds, serialize
- Graphs - grid flood, topo, union-find, shortest paths
- Dynamic programming - 1D / knapsack / LIS / grid / edit distance

Each topic deck lives under `<topic>/patterns/`. Problems are curated from `leetcode_dataset - lc.csv`. Correct answers reveal a Python sketch; the reference opens the LeetCode URL.
